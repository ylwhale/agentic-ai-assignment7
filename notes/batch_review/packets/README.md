# Prepared Evidence Packets

This directory contains machine-prepared evidence extracted
from recorded RepoMind traces.

The packets provide supporting source material, including
issue information, tool calls, and observed results.

They are not human-authored reviews, labels, or final
assessment decisions.

The completed historical human reviews are recorded
separately in `notes/trace-review.md`.

These packets are retained to support verification and
traceability of the reviewed runs.
